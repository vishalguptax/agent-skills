# Agent Skills

**Practical, tested skills for AI coding agents**, by [Vishal Gupta](https://github.com/vishalguptax). Each skill teaches an agent a complete, reliable way of doing one kind of job, with its references, templates and scripts included. They work in Claude Code and in any agent that supports [Agent Skills](https://agentskills.io): Codex, Cursor, GitHub Copilot, Gemini CLI, Windsurf, opencode and more.

Every skill here:
- **works from evidence:** it reads your project and asks when it can't find something, rather than inventing it;
- **stops for your approval** before anything hard to undo (installs, uploads, commits, publishing);
- **checks its own work** with real checks, not "should work";
- **is tested** against the same prompts run without the skill, with the test prompts in [`evals/`](evals/).

## Install

**Claude Code:** add the marketplace once, then install the skills you want:
```
/plugin marketplace add vishalguptax/agent-skills
/plugin install site-studio@vishal-agent-skills
```

**Any agent**, with the [skills CLI](https://github.com/vercel-labs/skills). It lists the skills in this repo and installs the ones you pick, into your agent's skills folder:
```
npx skills add vishalguptax/agent-skills
```

**By hand:** copy a folder from [`skills/`](skills/) into your agent's skills directory, for example `~/.claude/skills/<skill>/` (all projects) or `.claude/skills/<skill>/` / `.agents/skills/<skill>/` (one project).

## Use

Ask for the job in plain words. Each skill's description tells the agent when to use it, and its page in [`skills/`](skills/) lists example requests. In Claude Code you can also call a skill directly with `/<skill-name>`.

## Repository layout

```
agent-skills/
├── skills/<skill>/          one folder per skill
│   ├── SKILL.md             what the agent reads: frontmatter + workflow
│   ├── README.md            what people read: purpose, examples, how it works
│   ├── references/          detail the skill loads only when needed
│   ├── assets/              templates and files the skill uses
│   └── scripts/             deterministic helpers (no dependencies where possible)
├── evals/<skill>/           test prompts (evals.json) and fixtures for each skill
├── categories.json          the category list skills are filed under
├── template/                starting point for a new skill
├── scripts/catalog.mjs      validates skills; generates the catalog and marketplace
└── .claude-plugin/          Claude Code marketplace (generated)
```

## Adding a skill

See [CONTRIBUTING.md](CONTRIBUTING.md). In short:
1. Copy `template/` to `skills/<name>/` and rename `SKILL.template.md` to `SKILL.md`.
2. Write `SKILL.md` and its `README.md`, and add `evals/<name>/evals.json`.
3. Run `node scripts/catalog.mjs`.

CI fails if a skill is invalid or the catalog is stale.
